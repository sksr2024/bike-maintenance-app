# Explanation

このプロジェクトの目的は開発知識の習得。ユーザーがプロジェクトについて質問した内容に対する解説を、質問のたびにMDファイルとしてここに追加していく。

## ファイル命名規則

`NNNN-短い説明.md`（例: `0001-統合テストのglobalSetupとは.md`）。連番はこのフォルダ内の既存ファイルの最大値+1。

## 書き方

- 質問と回答の要約ではなく、その質問をきっかけに得られる知識を解説する体裁にする
- このプロジェクトの実際のコード・設定を具体例として引用する
- 一般論だけで終わらせず、「このプロジェクトではどうなっているか」に必ず接続する
