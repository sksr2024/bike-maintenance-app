# クラウドバックエンド構成（PostgreSQL + Node.js/TypeScript + React）を採用する

整備記録は端末内のみのローカル保存でも成立するシンプルな個人用データだが、本プロジェクトはアプリ機能の実装だけでなくバックエンド・インフラ領域の学習も目的としているため、あえてクラウド/バックエンド構成を採用する。データストアはPostgreSQL、バックエンドはNode.js + TypeScript、フロントエンドはReact + TypeScriptによるレスポンシブWebアプリとする。認証はOAuth等の外部プロバイダに頼らず、メール+パスワードによる自前実装とする（学習目的のため、仕組み自体を実装して理解する）。
